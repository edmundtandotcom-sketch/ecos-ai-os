## Programme doctrine

- Install, do not merely teach.
- Activity → evidence → realisation.
- Manual-first, then AI-amplified.
- Participants leave with operating assets, not only notes.
- The programme is property-business specific, not generic AI training.
- Client Advisory and Agent Edition examples must remain visibly separate.
