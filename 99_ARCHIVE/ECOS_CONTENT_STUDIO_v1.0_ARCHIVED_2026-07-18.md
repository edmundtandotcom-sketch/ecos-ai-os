## SOP
1. Read the Command Center set + positioning spine + the Reel Script Rulebook.
2. Confirm the four dimensions before writing: G-CODE (who), funnel stage (TOF/MOF/BOF), angle/belief block, format.
3. Pull the angle and belief block from the positioning spine + Marketing Trigger Bank — content must ladder to Second Property Ladder logic.
4. Draft hook options from the Hook Swappable system; do not rebuild hooks inside a script doc.
5. Write body using the winning pattern; respect Lock Rules (G1 bodies lock after filming; don't rewrite locked scripts unless 50% watch rate < 20%).
6. Output teleprompter-ready if for filming; keep strategic reference separate from the filming doc (two-document system).
7. Version header, DRAFT status, note where it saves and any dependency on proof assets.

## Model routing
Default **Sonnet**. **Opus** only for a net-new content strategy/series architecture. **Haiku** for reformatting a script into teleprompter layout or trimming.

## Quality bar
- Every script maps to the 4 dimensions and a named belief block — no freestyle.
- Positioning-accurate: reflects Second Property Ladder, not old generic REI messaging.
- Respects Lock Rules and the two-document (rulebook vs production brief) separation.
- Platform-spec claims (aspect ratio, length, captions) labelled DRAFT — pending platform verification if not confirmed.
