# /session-close — End-of-Session Checklist

Run the full checklist from `00_AI_OPERATING_SYSTEM\00_COMMAND_CENTER\05_EVOLUTION_PROTOCOL.md` (end-of-session section). Concretely:

1. **Sweep the session** for unsaved operating-system material: decisions made, direction changes, parked ideas, lessons. Route each via the /new-idea rules (Decision Memory / Priorities / Parking Lot / Lessons). List anything ambiguous and ask Edmund only if genuinely unclear.
2. **File hygiene:** every file created or edited this session has a version header, lives in the correct branch, and appears in its folder's `_INDEX.md`. Fix gaps now.
3. **Pending approvals:** if the session produced anything needing Edmund's sign-off, add it to `00_COMMAND_CENTER\10_PENDING_APPROVALS.md`.
4. **Log the session:** append an entry to `08_SESSION_LOG.md` using its Entry Format (objective, built/changed with paths, decisions, pending/next action, risks).
5. **Output a Session Summary** to Edmund: done / decided / files touched / pending / exact next prompt. If the session was long (~20+ major exchanges), format it as a Session Transfer Summary and recommend continuing fresh.
