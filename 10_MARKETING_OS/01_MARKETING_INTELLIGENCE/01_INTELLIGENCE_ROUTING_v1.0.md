# Marketing Intelligence Routing
Version: v1.0

| Need | Read from | Marketing output |
|---|---|---|
| Category, mechanisms, naming, approved positioning | `02_POSITIONING_AND_IP` | Channel/campaign application |
| Buyer psychology and research | `06_KNOWLEDGE_VAULT` | Hypothesis with source/freshness note |
| Client language or transcript evidence | Private evidence only | De-identified pattern after authorized review |
| Brand/proof availability | Brand/Proof registry + Asset Library | Asset selection pointer |
| Current campaign context | `03_ACTIVE_CAMPAIGNS` | Strategy/experiment decision |
| Sales conversion feedback | `11_SALES_OS` | Acquisition refinement |
| Tracking data | `08_OPERATIONS` | Performance decision |

Do not paste source documents into Marketing OS. Record only the marketing implication, source pointer, verification date and decision.
