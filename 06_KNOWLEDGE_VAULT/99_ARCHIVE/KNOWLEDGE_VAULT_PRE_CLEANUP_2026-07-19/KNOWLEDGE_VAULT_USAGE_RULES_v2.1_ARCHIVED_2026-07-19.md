## Simple Definition

Knowledge Vault is the reusable reference library. It preserves research, buyer language, proof, transcripts, swipes, and market context so future work is faster and sharper.

**It does not decide strategy.**

## Golden Rule

Active source files decide. Knowledge Vault improves.

- `03_CLIENT_ADVISORY_OS` decides advisory logic (Strategic Intent, belief blocks, conversation flow).
- `05_CONTENT_MARKETING_ENGINE` decides campaign production rules.
- `04_AGENT_EDITION_OS` decides recruitment/training logic.
- `08_OPERATIONS` decides tracking, CRM, and dashboards.
- Knowledge Vault contributes language, examples, proof, market context, and technique references — nothing here overrides an active source folder.

## Use Knowledge Vault For

- Better buyer language and objection-handling phrasing
- Market context (rates, policy, launches, sentiment) — verify freshness before public use
- Proof and case references
- Transcript-derived consult patterns
- Examples for scripts, ads, and landing pages
- Marketing/sales technique references (guru deep-dives)

## Do Not Use Knowledge Vault For

- Replacing active frameworks in `03_CLIENT_ADVISORY_OS` or `04_AGENT_EDITION_OS`
- Storing campaign working drafts (those live in `05_CONTENT_MARKETING_ENGINE`)
- Storing lead lists or dashboards (those live in `08_OPERATIONS`)
- Storing CRM SOPs
- Keeping old files just because they exist — archive instead

## Saving Rule

- Save campaign work inside `05_CONTENT_MARKETING_ENGINE`, not here.
- Save raw performance/tracking inside `08_OPERATIONS`, not here.
- Save reusable references here only if they improve future work across more than one campaign or consult.
- Save obsolete/superseded files in `99_ARCHIVE` (workspace root), never here.

## Promotion Rule

A Knowledge Vault item can influence an active source file only if it passes this test:

1. Is it repeatedly useful?
2. Is it broadly applicable beyond one campaign or one consult?
3. Does it improve decisions, language, proof, or strategy?
4. Does it conflict with a current active source file?
5. Is it current enough, or clearly marked historical?

If yes: extract the principle into the correct active source folder deliberately. Do not copy the whole old file blindly, and do not let a Vault insight silently override an active decision — route it through `00_COMMAND_CENTER\05_EVOLUTION_PROTOCOL.md`.

## Freshness Rule

Market, policy, rates, stamp duty (ABSD/TDSR/LTV/SSD), rental yield, pricing, and launch facts must be verified before use in public content or client advice. Knowledge Vault can hold old references, but old references must never control current advice. This mirrors the Platform Verification Rule in the root `CLAUDE.md`.
