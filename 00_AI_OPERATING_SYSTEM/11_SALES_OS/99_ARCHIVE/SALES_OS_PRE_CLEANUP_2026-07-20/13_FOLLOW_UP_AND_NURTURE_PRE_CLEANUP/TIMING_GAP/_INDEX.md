# TIMING_GAP — follow-up (incl. SUITABILITY note)
Version: v0.1 · Status: DRAFT · Date: 2026-07-11 · Supersedes: none
Sources: Risk Assurance v2.0 §9 (Fear Of Timing), §10 (lifetime review loop); Decision Psychology v2.1 RB-01/RB-03; RAM v1.0 SAYE

## Gap definition
Client stalls on market timing or "no rush" (RB-01, RB-03). Send market-context review, never hype. `[T3]`

| Field | Value |
|---|---|
| Objective | Replace "wait and see" with a dated trigger + the client's cost-of-waiting number |
| Assets | Market-context review (factual); cost-of-waiting worked number; case study (Missed Window / Strategy Over Comfort); readiness plan (SAYE) |
| Channel | Email (market context) → WhatsApp; scheduled review touch at the trigger date |
| Timing | Context review within 1 week; then align to the client's named trigger (MOP/TOP/SSD/rate/family milestone) |
| Owner | Consult advisor |
| Exit condition | Client sets a dated trigger/review → NURTURE (long-term-nurture) with next Ascent trigger |

## SUITABILITY note (handled here, not a separate gap)
Where the real issue is *readiness/fit* (not enough capacity/timing yet) rather than fear, convert "not now" into a **SAYE readiness plan**: target entry amount · monthly saving · capital gap · dated review · future trigger (RAM Technique 5). A suitability-driven timing gap resolves to NURTURE (`long-term-nurture`) or NO FIT (`not-suitable`) if no path exists — never open-ended. `[T5]`
