## Purpose
Reusable competitor-ad pattern library, fed weekly by the ads-brief automation. Registries and analysis
only — raw video/image/transcript files live in
`01_ASSET_LIBRARY/03_CREATIVE_INTELLIGENCE/03_EXTERNAL_REFERENCE_SWIPES/<Advertiser>/`; this library links
to them, never duplicates them.
