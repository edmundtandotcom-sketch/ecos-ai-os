## 2. DOOR: LEGACY LAUNCH — OPERATING CORE

**Full source:** `01_CAMPAIGN_LEGACY_LAUNCH/01_ACTIVE_FOUNDATION/01_LL_CAMPAIGN_BRIEF_ACTIVE_v1.0.md` (active brief) + [LL]-tagged entries in `04_TRIGGER_MARKETING/MAS_TRIGGER_MARKETING_BANK_v1.0.md` (trigger copy, decouple-specific framing)

- **Belief-shift sequence:** "I'm fine because I have equity" → "appreciation is not progression" → "there's a structure (decouple) I haven't been shown" → "the window (ABSD, pricing) isn't infinite" → "show me my specific numbers."
- **Offer path:** Soft CTA (comment/WhatsApp "REVIEW") → Property Position Checklist → 1-Hour Property Position Review / Legacy Launch Clarity Consult.
- **Message boundaries (from active brief):** avoid guaranteed profit, buy-now urgency, fear countdown, "all owners should sell/decouple," project hype.

## 3. DOOR: FAMILY LEGACY — OPERATING CORE

**RETIRED (Decision 058, 2026-07-11) — retained as reference for future reactivation.** Not an active marketing door; do not build new creative against this section without a fresh Edmund ruling.

**Full source:** `02_CAMPAIGN_FAMILY_LEGACY/MAS_CAMPAIGN_FAMILY_LEGACY_STRATEGY_v1.0.md`

- **Entry trigger:** Parent (48–65) with 1 paid/near-paid property + idle capital ($150K–$500K+ in FD/savings/CPF OA) + a working child (23–32, $3.5K–$7K/mo income).
- **Angle:** Lead with the parent's aspiration to leave something, not the child's difficulty affording property. Idle capital framed against FD (safety-anchored), never against stocks.
- **Belief-shift sequence:** Recognition ("about my family, not a pitch") → Possibility (a real financial structure exists) → Hope (idle capital + child's income can actually do this) → Urgency (child's ABSD-free window) → Readiness ("show me our numbers").
- **Offer path:** Family Legacy Planning Session / Child's First Property Review / Idle Capital Assessment → Conversation 1 (dual discovery, REI Method on both parent and child) → Conversation 2 (ProDeck, combined Ascent trajectory) → decision (co-purchase or idle-capital-only).
- **Hard rules:** both generations must eventually be present; never pitch a specific property in marketing; BNTTS reframe (property as vehicle) must land with the child from the first conversation; don't force co-purchase if idle-capital-only is the better fit.

## 4. DOOR: MASH-UP — OPERATING CORE

**RETIRED as a marketing door (Decision 058, 2026-07-11) — retained as reference for future reactivation.** Not an active marketing door; do not build new creative against this section without a fresh Edmund ruling. Scope note updated per **Decision 063 (2026-07-11, same day)**: the A4 "Mash-Up" ADVISORY delivery pattern is now ALSO retired — the A3/A4 ascent levels are removed entirely (Ascent Model = A0–A2; Decisions 053(b)/062 superseded); multi-name/family situations run inside standard A1/A2 engagements.

**Full source:** `03_CAMPAIGN_MASHUP/MAS_CAMPAIGN_MASHUP_STRATEGY_v1.0.md`

- **Entry trigger:** Not a standalone top-of-funnel door — it is a mid-funnel *upgrade* discovered during Conversation 1 of Legacy Launch or Family Legacy, when a family qualifies for **both** SI-05 (decouple-viable joint condo) and SI-06 (first-time-buyer-clean working child) and timing can coordinate inside 6–12 months.
- **Angle:** One coordinated plan beats two sequential campaigns — the power is in the coordination, not the sum of the parts.
- **Belief-shift sequence:** Recognition ("two problems, one solution") → Curiosity (how are these connected?) → Excitement (three-property portfolio without selling) → Conviction (most efficient use of everything we have) → Action ("all of us, at once, see the numbers").
- **Offer path:** Mash-up Qualifier Check (6-point checklist) → Comprehensive Family Strategy Session → dual scenario build → extended ProDeck (both SIs) → sequencing decision (decouple first vs. parallel) → dual execution support.
- **Hard rules:** build both scenarios before Conversation 2; present combined household Ascent trajectory, not two individual ones; address child's BNTTS separately from parent's; sequence clarity is the #1 failure point; every completed Mash-up becomes a case study.
