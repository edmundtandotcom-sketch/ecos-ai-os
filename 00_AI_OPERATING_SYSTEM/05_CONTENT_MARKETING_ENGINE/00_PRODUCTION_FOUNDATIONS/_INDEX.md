## Use rule

Start with the current category, audience, route, offer and campaign brief. Apply only the production rules that improve delivery.

Do not revive retired campaign-door, Ascent A3/A4 or SI-06 classifications merely because an older rulebook contains them.

## Output boundary

Working scripts and creatives belong in Active Campaigns. Finished reusable outputs are promoted to Asset Library after approval.
