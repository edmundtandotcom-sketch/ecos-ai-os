### FR-04 — MAS Content Hierarchy / Trigger Marketing Bank
**Purpose:** Move a prospect Awareness ("that's about me") → Interest → Desire → Trigger ("I should talk to someone"). **Best use:** any ad hook, video hook, email subject, or caption for Legacy Launch [LL] (the [FL]/[M] doors are RETIRED per Decisions 058/063 — reference only). **Not for:** Agent Edition (Client engine only). **Inputs:** campaign door tag, belief block, life trigger. **Structure:** tag every message [LL]/[U] (legacy [FL]/[M] tags are retired-reference); write toward the next hierarchy level, never past it in one asset. **Failure mode:** jumping straight to Trigger-level copy on cold PA traffic — reads as pushy, breaks the "invite, not pressure" rule. **Evidence:** Tier 5. **Source:** `05_CONTENT_MARKETING_ENGINE\04_TRIGGER_MARKETING\MAS_TRIGGER_MARKETING_BANK_v1.0.md`.

### FR-05 — Villain Rotation Framework
**Purpose:** Rotating external-threat attack layer over the permanent Market Maker spine — each of 14 villains is a different front door into the same 3-stage pivot. **Best use:** cold ad hooks (Voice A — Challenger/Authority) or warm email/VSL (Voice B — Peer/Practitioner) when a live market event creates fear or urgency. **Not for:** Client Advisory (Agent Edition only — never blend). **Inputs:** villain selection tied to a real, current market event; full hook stack (ad/landing/email/video). **Failure mode:** deploying a villain with no live market trigger — reads as manufactured urgency. **Evidence:** Tier 5. **Source:** `04_AGENT_EDITION_OS\00_POSITIONING\MAS_VillainBank_v2.0_CANDIDATE.md`.

### FR-10 — 4 Master Ad Angles (System / Plateau / Market Shift / Identity)
**Purpose:** Four anchor angles to test Agent Edition cold and warm ad copy against, in cold-to-warm order. **Best use:** System angle first on cold traffic (highest documented cold performer per the source doc's own claim — unverified against real REI spend); Identity/Plateau on warm retargeting. **Not for:** first-touch identity-level copy on cold audiences — tests worse per the same source claim. **Inputs:** angle selection, hook pattern, example copy. **Failure mode:** using Identity angle cold — burns spend before trust exists. **Evidence:** Tier 5, **STALE (C05)** — re-verify against Market Maker Method before use; do not reuse "3C"/"Bootcamp" language. **Source:** `04_AGENT_EDITION_OS\02_MARKETING\MAS_MARKETING_INTELLIGENCE_OS_v1.md` §3.

### FR-12 — PAS (Problem-Agitate-Solution)
**Purpose:** State the problem, agitate the cost of inaction, present the solution. **Best use:** short-form ad copy or email needing a fast, linear structure. **Not for:** authority-building long-form (too thin to carry 45 minutes). **Inputs:** problem statement, agitation detail, solution/offer. **Evidence:** Tier 4, generic industry structure — not sourced from a workspace file. **Status:** Available, unproven here.

### FR-13 — AIDA (Attention-Interest-Desire-Action)
**Purpose:** Classic linear attention-to-action structure. **Best use:** any ad or landing page needing a simple, well-understood spine as a fallback when no REI-specific framework fits. **Not for:** trust-led cold hooks where the objection needs pre-empting before attention alone will convert (use FR-10 System angle or FR-04 instead). **Evidence:** Tier 4, generic — not sourced from a workspace file. **Status:** Available, unproven here.

### FR-15 — Before-After-Bridge (BAB)
**Purpose:** Current painful state → desired future state → the bridge (offer) connecting them. **Best use:** short ad copy, email, or testimonial-style content. **Not for:** cold traffic with no established pain recognition yet — BAB assumes the "before" is already felt. **Evidence:** Tier 4, generic — not sourced from a workspace file. **Status:** Available, unproven here.

### FR-16 — 4 Ps (Promise-Picture-Proof-Push)
**Purpose:** Make a promise, paint the outcome, prove it, push for action. **Best use:** sales-letter-style long copy or as the VSL script backbone (pairs naturally with FR-01's Story block for the Picture/Proof stages). **Not for:** short-form Reel copy — too many beats for 120 seconds. **Evidence:** Tier 4, generic — not sourced from a workspace file. **Status:** Available, unproven here.
