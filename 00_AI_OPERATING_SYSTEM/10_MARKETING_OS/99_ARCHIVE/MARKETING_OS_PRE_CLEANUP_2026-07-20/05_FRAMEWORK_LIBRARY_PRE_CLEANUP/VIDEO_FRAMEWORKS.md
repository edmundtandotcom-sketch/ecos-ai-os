### FR-01 — Hook-Story-Offer Universal Spine
**Purpose:** One structural spine (Hook → Story → Offer) for every video length: 120–180s Reel, 4–6min VSL, 45min YouTube. **Best use:** any REI video ad, any length — the timing blocks scale, the structure doesn't. **Not for:** organic non-sales content with no CTA (the spine assumes an Offer close). **Inputs:** one Hook type (Call-Out, Open Loop, Hard Truth, Contrarian); Story blocks in fixed order (Mirror → optional Lie → Hard Truth → Reframe → Method → Proof); ONE proof type (Track Record, Someone Else's Win, Your Own Story, Warning Story). **Structure outline:** Reel = 0–3s Hook / 3–35s Mirror+Lie / 35–50s Hard Truth / 50–80s Reframe / 80–105s Method+Proof / 105–120s Offer. VSL and YouTube stretch the same blocks proportionally. **Failure mode:** skipping the Hard Truth (softens too early) or using more than one proof type (dilutes trust). Score below 70/100 on the built-in rubric = rewrite, not film. **Evidence:** Tier 5 for REI's application; the structure itself was validated against the 1CC Live breakdown (Tier 4, third-party). **Status:** APPROVED MASTER. **Source:** `05_CONTENT_MARKETING_ENGINE\00_FOUNDATIONS\REI_Video_Production_Foundation_v1.1.md`.

### FR-02 — G-Code × Awareness × Pattern × Angle Generation Matrix
**Purpose:** Generate and track Legacy Launch's Pack 1 ad variations — 27 body scripts × 8 hooks = 216 combinations across 6 behavioural G-codes (G1 Idle Millionaire, G2 Comfortable Compounder, G3 Worried Watcher, G4 Legacy Builder, G5 Retirement Rusher, G8 Spouse Alignment). **Best use:** Reel ad variation planning for a single campaign's structured rollout, one G-code + awareness stage + pattern + angle combination per asset. **Not for:** treating G-codes as identical to the Buyer Segment Library's client-psychology segments (see `02_CUSTOMER_INTELLIGENCE\SEGMENT_USAGE_GUIDE.md` — the two systems are not mapped 1:1). **Inputs:** G-code selection, PA/SA/PA2 stage, script pattern (9 named patterns e.g. PRIVATE_THOUGHT, DIRECT_DIAGNOSIS), angle code, CTA code. **Structure:** only G1 has full SCRIPT READY scripts (7 bodies); G2–G5 and G8 are STRUCTURE BRIEFS ONLY — do not film until G1 Pack Lock (20 qualified leads + 5 consultations + 1 creative winner) is hit. **Failure mode:** filming G2–G8 before Pack Lock — burns budget on unvalidated patterns before the winning pattern from G1 data is known. **Evidence:** Tier 5, explicitly zero market data at build time. **Status:** CANDIDATE. **Source:** `05_CONTENT_MARKETING_ENGINE\00_FOUNDATIONS\LAYER_3A_REEL_SCRIPT_RULEBOOK_v1.1.md`.
