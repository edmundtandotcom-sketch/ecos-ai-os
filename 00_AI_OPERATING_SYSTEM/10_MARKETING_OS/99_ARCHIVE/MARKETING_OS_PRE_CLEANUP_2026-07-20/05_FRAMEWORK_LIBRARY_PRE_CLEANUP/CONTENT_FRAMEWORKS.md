### FR-03 — YouTube Authority Engine
**Purpose:** Production control system for long-form YouTube episodes (45–60min authority, 20–30min explainers, 8–12min authority videos) that double as mother assets for downstream reels, shorts, carousels, email, and WhatsApp content. **Best use:** authority positioning, YouTube SEO, and pipeline warmup — explicitly not a direct-conversion format. **Not for:** treating as interchangeable with the short-form Video Script Engine — the source doc is explicit these are separate control systems ("Do not overload the Video Script Engine with 45-60 minute logic"). **Inputs:** a guided direction intake (who it's for, what belief/problem/question, format length, title/thumbnail promise, proof/examples, CTA path, playlist placement, intentional clip-extraction plan) run *before* scripting. **Structure outline:** thumbnail = 50% of the hook; first 2 minutes carry the whole game; one episode = one problem group, never mixed; end screens link to the matching Reel ad for that problem group. **Failure mode:** writing the full script before the direction intake is clear — the source doc's core rule is "DO NOT write the full YouTube script immediately unless the episode direction is already clear." **Evidence:** Tier 5, unlaunched. **Status:** ACTIVE MASTER ENGINE. **Source:** `05_CONTENT_MARKETING_ENGINE\01_CAMPAIGN_LEGACY_LAUNCH\01_ACTIVE_FOUNDATION\07_GLOBAL_YOUTUBE_AUTHORITY_ENGINE_ACTIVE_v1.1.md`.

### FR-11 — Deep Buyer Profile Method
**Purpose:** Master-prompt method for building psychological/decision-style deep buyer profiles, used to prep consults and write buyer-language-accurate content. **Best use:** pre-campaign audience research and consult prep — a research input, not a finished asset format. **Not for:** direct copy generation without a human synthesis pass. **Inputs:** buyer interview/consult data, decision-style questions. **Structure:** unknown in detail — content exists only as `.md.docx` (a Markdown-named file saved as Word), duplicated at two locations with unconfirmed canonical status (C17). **Failure mode:** treating either duplicate as automatically canonical without checking modified dates first. **Evidence:** N/A — method, not a performance claim. **Status: DRAFT — pending .md conversion.** **Source:** `06_KNOWLEDGE_VAULT\02_BUYER_PSYCHOLOGY\DEEP_BUYER_PROFILE_METHOD_REGISTRY.md` (registry pointer only).

### FR-14 — Myth → Reframe
**Purpose:** Generic structure — state a common myth/belief, disprove it, install the correct frame. **Best use:** myth-bust content, authority-building video or carousel, FAQ content. Pairs naturally with FR-03's long-form authority format and with the Reframe block already inside FR-01's Hook-Story-Offer spine. **Not for:** short-form Reel hooks — myth-busting needs room to land evidence before the reframe. **Inputs:** named myth, evidence against it, correct frame, proof. **Evidence:** Tier 4, generic industry structure — not sourced from a workspace file. **Status:** Available, unproven here.
