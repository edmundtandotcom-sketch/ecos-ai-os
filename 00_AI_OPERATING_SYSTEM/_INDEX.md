## Routing Boundaries

- Active campaign briefs, scripts, working media, links and results → `03_ACTIVE_CAMPAIGNS`
- Approved reusable assets and raw/editable production sources → `01_ASSET_LIBRARY`
- Client/contact PII and named transcript evidence → `00_E.C.O.S_CLIENTS_PRIVATE`
- Software runtime and repositories → local runtime/private Git; recovery packages may live in `_BACKUPS`
- Newly generated unclassified artifacts → root `Artifacts` for seven-day triage only
- Non-secret self-contained static artifacts → owning campaign/OS tool-artifact folder with an index/registry; never source or deployment authority
- Uncertain or deletion-candidate items → relevant review, quarantine or archive folder

One permanent file has one permanent home. Indexes and routing pointers may reference that file but must not duplicate it.
