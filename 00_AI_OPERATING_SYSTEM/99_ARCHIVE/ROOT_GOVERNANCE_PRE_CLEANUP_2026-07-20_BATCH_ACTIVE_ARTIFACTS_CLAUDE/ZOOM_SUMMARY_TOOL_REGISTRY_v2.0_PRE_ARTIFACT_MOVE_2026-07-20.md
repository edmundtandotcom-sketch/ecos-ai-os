## Purpose

Registry entry for the Zoom-summary workflow and its implementation boundary. This file contains no client evidence and is not a source-code repository.

## Governing rules

- Named recordings, transcripts, summaries and per-consult evidence belong in `00_E.C.O.S_CLIENTS_PRIVATE`.
- De-identified reusable findings may be promoted into the Knowledge Vault after review.
- Runtime/code belongs in local runtime/private Git where applicable.
- Operations owns workflow configuration, access, retention, error handling and monitoring.
- Never treat an old Drive copy or filename as proof of the deployed version.
- Verify the current source repository, deployment, consent settings and retention policy before changing or running the tool.
