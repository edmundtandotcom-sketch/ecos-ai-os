# Second Property Ladder — Start Here

## Purpose

This package is the clean handover layer for continuing the Second Property Ladder build in Claude Code without losing the strategic decisions already made.

It is designed to prevent three problems:

1. Claude treating every historical statement as approved.
2. Old drafts overriding newer decisions.
3. The project expanding into an over-engineered operating system before the marketing foundation is finished.

## Recommended working model

Use **ChatGPT as the strategy workshop and final challenger**.

Use **Claude Code as the workspace executor** for:

- reading the wider Claude Workspace;
- consolidating and updating Markdown files;
- creating folder structures and indexes;
- maintaining Decision Memory;
- building approved assets;
- checking for contradictions and duplicated masters;
- producing implementation files.

Do not allow both systems to independently redefine the business.

### Authority rule

`01_LOCKED_DECISIONS_PHASE_1.md` is the current source of truth for this work package.

The files in `90_SOURCE_MARKDOWN/` are research and workshop sources. They contain useful material, but they also contain older suggestions, duplicated sections and decisions that have since changed.

When a source document conflicts with the locked decisions:

1. Keep the source unchanged.
2. Follow the locked decision.
3. Record the conflict in the change log.
4. Do not silently blend both versions.
