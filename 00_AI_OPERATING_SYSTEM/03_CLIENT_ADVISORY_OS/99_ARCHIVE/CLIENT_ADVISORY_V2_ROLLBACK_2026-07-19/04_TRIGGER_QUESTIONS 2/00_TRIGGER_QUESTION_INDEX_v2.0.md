## 1. Folder Rule

This folder stores advisory trigger questions used to help clients self-diagnose their position, belief block, risk concern, readiness, and next action.

It is not a marketing hook folder.

A trigger question should help the advisor create clarity inside a live or prepared advisory conversation. It should not be used as raw ad copy unless Content Marketing Engine deliberately adapts it.

## 6. Current Governing Rules

Use the latest Client Edition decisions:

- Ascent Stage is the only active level system.
- A0 / Activation is not a standalone active stage. It is an awareness moment inside A1 First Climb.
- Property Position is context only, not a second ladder.
- HDB/EC is only a qualified upgrade-window segment when timing, capacity, ownership/name relevance, and advisory fit are real.
- DINK is an important buyer segment and may become a campaign pack later.
- Decoupling can become its own campaign pack, but internally it remains a mechanism that opens the next decision.
- Public copy must stay simple; internal labels may be precise.

## 7. How To Use This Folder

Before asking a question, identify:

1. Ascent Stage;
2. Property Position;
3. Buyer Segment;
4. Strategic Intent;
5. Belief Block;
6. Readiness / Tier;
7. Desired Next Action.

Then choose questions from the relevant v2 file.

Do not run every question. Use the smallest set that creates clarity.

## 8. Final Rule

Trigger questions are not scripts to recite.

They are tools to help the client say the truth in their own words.

If the question does not improve diagnosis, self-realisation, decision confidence, or next-action clarity, do not use it.
