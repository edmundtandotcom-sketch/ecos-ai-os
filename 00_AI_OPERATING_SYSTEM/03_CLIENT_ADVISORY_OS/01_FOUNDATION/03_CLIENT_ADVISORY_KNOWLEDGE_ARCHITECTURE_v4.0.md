## Core rule

Store by job and authority, not by the conversation in which an idea appeared.

## Promotion flow

Observation or transcript evidence → candidate insight → validated reusable learning → correct branch master.

Campaign output does not become permanent knowledge merely because it exists. It is promoted only after validation and clear reuse value.

## Retrieval order

Command Center → Positioning & IP → Client Brain → Foundation → relevant advisory subsystem → Knowledge Vault → archives.

## Privacy rule

Sanitise and de-identify before promoting client-derived insight. Public use requires consent and source verification.

## No-bloat rule

Do not create a parallel folder system inside Client Advisory. Use the existing six folders and archive.

## Final rule

A reusable fact has one authoritative home. Other files link to it rather than duplicate it.
