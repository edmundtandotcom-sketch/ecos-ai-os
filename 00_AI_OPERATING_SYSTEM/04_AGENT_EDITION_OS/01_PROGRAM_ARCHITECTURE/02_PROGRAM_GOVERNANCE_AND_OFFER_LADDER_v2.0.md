## Programme doctrine

- **The 3×3 is a diagnostic map, not a curriculum, taught to recognition not competency.** ~90 minutes covers all nine at recognition level (~30 min/pillar). Members self-score red/amber/green and commit to exactly two (the 3-2-1 mechanism: diagnose 3 pillars, choose 2 multipliers, install 1 live before leaving).
- **The room follows PLAN → EXPERIENCE → PERSONALISE → QUEUE, not "build it live."**
  1. **Plan** — the member manually designs the process first, with no automation ("if you had to send every message yourself, what would you send, when, why?"). This is what makes the automation legible later, not a wasted step.
  2. **Experience** — walk the painful manual version at volume ("now imagine doing this 25 times a month") so the value of what's revealed next actually lands.
  3. **Personalise** — reveal the prebuilt Snapshot/GPT-assisted system (80% done). The member customises only what's theirs: message, video, case study, timing, CTA.
  4. **Queue** — ready for specialist installation. Not installed live.
  Never reveal the prebuilt system before the member has felt the manual pain — the reveal is the payoff, not the opener.
- **Four-layer implementation hierarchy:** Boardroom (business decisions + personalisation) → Snapshot/GPT (80% prebuilt) → Specialist Call (technical configuration) → Agent (activate/use). Edmund is the architect; specialists are installers; the room never becomes a technical-support session.
- **An explicit scope boundary is taught early, not discovered late:** what we WILL do (diagnose, decide, map, customise assets, test, start Priority #1) vs. what we will NOT do (configure every workflow, connect every account, finish all nine multipliers) vs. what happens after (specialist Installation Labs). Prevents the "why isn't my CRM finished" complaint.
- **One live result per person, non-negotiable.** Something real goes live before the room ends, even if the full technical build happens later.
- Sell the destination in marketing; install the vehicle in the room.
- Manual-first, then AI-amplified. AI never replaces professional judgement.
- The programme is property-business specific, not generic AI or sales training.
- **Agent Edition does not teach the consultation/presentation methodology itself.** Whatever the agent already uses stays theirs — the value is before the meeting, after the meeting, and the infrastructure connecting them. Deeper consultation work is optional, Year 2 ("Advisory Conversation Lab"), never Core Foundation.
- Client Advisory and Agent Edition examples must remain visibly separate — never blend engines in one asset.
