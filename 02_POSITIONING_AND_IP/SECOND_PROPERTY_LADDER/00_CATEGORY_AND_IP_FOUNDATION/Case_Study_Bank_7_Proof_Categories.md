**THE CASE STUDY BANK**

**Proof Against the 7 Proof Categories**

*The repeatable proof system of The Second Property Ladder™: what each case type proves, where it deploys, the universal template every case is written from, and the harvest engine that keeps the bank filling.*

REI Advisory · Coach Edmund Tan & Cindior Ho · Singapore Real Estate Insider

Version 1.0 · 9 July 2026 · Categories quarried from CategoryKing V.1.2 (Rank 3), aligned to Mechanism v1.3 (Rank 2\)

**WHAT THIS IS.**  Proof is never presented as random testimonials. Every case in the bank is filed under one of 7 repeatable proof categories — each engineered to break one specific false belief and prove one part of the Ladder. The bank feeds the D5 follow-up email (“a case study matching their Move”), the ads, the VSL, the session, and the six content pillars — from one master version per case.

**THE RULE.**  Every case proves the ORDER, never the pick. If a case reads as “we chose a winning property”, it is off-category and does not enter the bank — no matter how good the numbers are. The category sells sequence. The proof must too.

**1\. Why Proof Categories, Not Testimonials**

* A testimonial praises the advisor. A proof category proves the mechanism. The first builds a personality; the second builds a category king.

* Categories are repeatable: every new client outcome slots into an existing shelf, so the bank compounds instead of scattering.

* Categories are targetable: each maps to a diagnostic Result page and a false belief — so automation can send the RIGHT proof to the RIGHT Move, not a highlight reel.

* Categories are trainable: MAS Agent Edition agents learn to spot, capture, and file proof the same way — the bank becomes a system asset, not a founder asset.

**2\. The 7 Proof Categories**

**Case Type 1 · The Exit That Unlocked the Next Move**

| Field | Definition |
| :---- | :---- |
| **Who it features** | A Property Climber who was stuck — equity present, motion absent — until the exit was planned first. |
| **False belief it breaks** | “I can’t move until the market/my situation changes.” The block was never the market; it was the unplanned exit. |
| **Moves it proves** | Move 4 (Research the Exit First), supported by Move 3\. |
| **Serves results** | R4 primary · R5 secondary · P-grade (Portfolio) secondary. |
| **Deploy surfaces** | D5 email (Move 4\) · VSL proof block · YouTube pillar: Exit Before Entry™ · session close. |

**THE MONEY LINE.**  They weren’t stuck because of money. They were stuck because no one had planned the exit.

**Story beats:** Position frozen for years → the Map showed the exit, not the entry, was missing → exit researched and dated → the next move unlocked itself → motion within one window.

**Case Type 5 · Two-Name Advantage**

| Field | Definition |

**THE MONEY LINE.**  The structure decision was worth more than the property decision.

**Story beats:** Two names, one plan → structure options mapped BEFORE any purchase → the lawful structure chosen early → a path open that late deciders lose.

**COMPLIANCE — CASE TYPE 5\.**  Structure stories are the highest-risk proof in the bank. Feature ONLY structures that are lawful in substance and in form; never frame any arrangement as a stamp-duty workaround — IRAS has pursued contrived 99-to-1 arrangements, and CEA holds marketing to account. Every Case Type 5 story passes legal/compliance review before ANY deployment, and stays out of cold ads by default.

**4\. The Universal Case Template (write every case from this)**

One master written version per case, in six beats, 350–500 words. All derivatives (60-second video script, D5 email, carousel, session tell) are cut from the approved master — never written fresh.

| Beat | What it must contain |
| :---- | :---- |
| **1 · THE POSITION** | Who they were (anonymised profile: ages, household shape, income band — rounded), what they held, and the numbers that matter. Real, rounded, verifiable. |
| **2 · THE TRAP** | The false belief they carried — in their own words where possible. Name the villain when it fits: the One-Property Trap, Exit-Later Buying, the closing window. |
| **3 · THE MAP** | What the Position Map made visible — the number or date that changed the conversation. This beat sells the session without selling. |
| **4 · THE ORDER** | The sequence decision: which path, in what order, and WHY — the reasoning is the product. This beat carries the category. |
| **5 · THE MOVE** | What they executed and when. Facts only — dates, actions, structure. No drama needed; the order IS the drama. |
| **6 · THE OPTIONS** | The outcome stated in options and position — never as promised returns. Close on the Law or the money line, then the one CTA. |

**Writing Rules (non-negotiable)**

* **Real clients only. Written PDPA consent on file before drafting begins; anonymised by default, named only with explicit written consent.**

* Numbers rounded but verifiable — every figure traceable to a document in the client file. Proof that cannot survive scrutiny is not proof.

* No forecasted returns, no performance promises, no “guaranteed” anything — outcomes are stated as what happened, options are stated as what opened.

* Property names appear only as historical fact of what a client did — never as a recommendation. The case proves the order, not the pick.

* Vocabulary check on every draft: Move, Next Move, Property Climber, Exit Before Entry™ — banned words absent.

* Every published case passes CEA advertising-compliance review and carries the standard disclaimer line.

**6\. The Harvest Engine (how the bank fills)**

| Source | Method |
| :---- | :---- |
| **Zoom consultation archive** | Run the scoped Faster-Whisper transcription pipeline over the archive; mine transcripts for the 7 patterns (stuck-then-exit, comfort language, path switches, structure decisions, missed windows, walked-away purchases). Tag candidates by case type. |
| **Next Move Strategy Session™s** | At session close, the run sheet’s copy is filed; any page showing a category-true story gets a CRM tag: case\_candidate \+ case\_type\_1..7. |
| **Transaction milestones** | Completed moves trigger a review: which category does this outcome prove? Consent request goes out with the congratulations message — the moment goodwill peaks. |
| **Quarterly harvest sprint** | Once a quarter: review all tagged candidates, pick the strongest per empty shelf, obtain consent, draft to template, compliance-review, publish master \+ derivatives. |

* Template’s six beats present; money line lands; ends on the one CTA.

* Vocabulary compliant; banned words absent; no return promises; CEA review passed.

* Routed: primary/secondary slots in Section 3 updated so automation always has a live case per Move.
