### Correction — real visible defect missed at first publish (2026-07-17)

Edmund reported the published prototype looked broken: overlapping text, dated design. My first QA pass had only verified logic via DOM/console inspection and a build agent's self-reported browser test — it never actually looked at the rendered page. On review with real screenshots (the sandboxed preview browser's screenshot tool has a known compositor bug on backgrounded tabs and gave false readings both ways — a false "massive blank gap" and initially-contradictory geometry checks — until verified through a properly-foregrounded browser session), found a genuine bug: the case-study section's `.case-card` two-column layout (`display:grid`) rendered with a container height far shorter (~584px) than its actual text content (~1138px), because a CSS Grid row-track-sizing interaction with the video-placeholder's `aspect-ratio:16/10` sibling caused Chrome to size the row incorrectly. The overflowing text rendered on top of the next section (Cost of Waiting), exactly matching Edmund's report. Confirmed via screenshot before and after.

**Fix:** changed `.case-card` from `display:grid` to `display:flex` with explicit `flex` values on its two children — flexbox does not have this row-sizing failure mode for mismatched-height siblings. Verified via screenshot on both Door A and Door B (same shared CSS) that the case-study section now transitions cleanly into the next section with no overlap, and that the rest of both pages (hero, objection cards, 5-step process, offer-bridge, FAQ, final CTA, all 12 angle-hero variants) render cleanly with proper spacing, correct door-specific accent colors (brass/Door A, moss/Door B), and no dated/broken appearance.

**Lesson for future artifact QA:** DOM geometry checks and a subagent's self-reported testing are not a substitute for actually looking at the rendered page in a properly-foregrounded browser. Screenshot-based visual verification is required before publishing any visual/interactive artifact, not just after a user complaint.
