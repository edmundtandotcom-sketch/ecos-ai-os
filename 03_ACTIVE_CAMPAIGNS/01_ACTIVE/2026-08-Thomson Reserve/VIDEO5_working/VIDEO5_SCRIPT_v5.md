# THOMSON RESERVE — THE LAYOUTS, ONE BY ONE
## Script v5 · 26 Sep 2026 · supersedes v4

**What changed from v4.** Same eleven layouts, same facts, same numbers. Three
things are different: it's written to be *watched*, not read; the language is
plain; and the camera moves.

**The shot grammar** — three shots, marked on every block:

| Mark | What's on screen |
|---|---|
| `[FULL]` | Edmund full frame. No graphics. Used for hooks, verdicts, CTAs, and every "here's what I'd do". |
| `[BOARD]` | The 16:9 two-up board — TR plan left, neighbour right, grid and transaction underneath, PiP bottom-right. |
| `[BOARD+]` | Same board, one thing highlighted — a room, a door, a number. |

Rule for the edit: **never more than 45 seconds on `[BOARD]` without a cut
to `[FULL]` or a `[BOARD+]` highlight.** The layout is the evidence; Edmund is
the show.

**Engagement is fixed in advance** so there's no gap over four minutes:

| Kind | Where | What it does |
|---|---|---|
| 🎣 **Hook** | top of every segment | one line that makes them stay for that layout |
| 🤔 **Guess first** | inside beats ② and ④ | ask, pause, then answer — pattern interrupt |
| 🔁 **Open loop** | planted in OPEN, paid off in A2, A7, Module B, Module C | "I'll show you" — then show |
| 💬 **Micro-CTA** | every 3–4 min, marked | comment / poll / save / subscribe / session QR — rotated, never the same two in a row |
| 🎯 **Macro CTA** | close | topic-matched, plus the next-video tease |

**Plain language.** Every technical word appears once with a five-word
meaning, then never again as jargon. The list is at the end so the captions
and the on-screen tags match.

**Runtime — measured, 5,230 spoken words at 150 wpm and 1.15×: 30 min delivered in total.** Per assembly: 2-bed 12.6 · 3-bed 11.3 · 4/5 9.2 · site 3.4 min. Longest gap between CTAs in any cut: under 4 min, checked.
