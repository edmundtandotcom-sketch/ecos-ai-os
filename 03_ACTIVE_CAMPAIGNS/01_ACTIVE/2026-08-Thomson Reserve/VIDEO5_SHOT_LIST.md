# VIDEO 5 — SHOT LIST · displays keyed to the v6 script
## 28 Sep 2026 · pairs with `VIDEO5_SCRIPT_v6_EDMUND.md` and `VIDEO5_displays/`

**How to use this while recording.** Every row is one display. Read the
trigger phrase; that's the word the display cuts on. The template column
names one of eight fixed frames (rendered examples in `VIDEO5_displays/`), so
the editor picks, never designs. Variation comes from rotating templates, not
inventing new ones.

**The eight templates** — all 1920×1080, all keep the same three zones:
content stops at y=850, subtitles own y 930–1040 (x 160–1560), PiP is the
260 px circle bottom-right.

| Code | Frame | Use it for |
|---|---|---|
| **S1** SITE FULL | whole site plan, blocks outlined, cluster legend, compass | the once-per-video set-up; any "where are we" moment |
| **S2** SITE ZOOM | one block filling the left, stack ringed, distance arrow drawn, compass with facing needle, fact panel right | the facing block in every layout — the workhorse |
| **S3** SITE + PiP ZOOM | whole site plan, stacks ringed, zoomed block in an inset with a leader line | when the point is *where on the site* rather than *what's opposite* |
| **S4** VIEW | developer drone photo full-width, level ladder right, compass | "what you'll see" — always straight after S2 |
| **L1** LAYOUT FULL | plan on a card, fact panel right | the first look at every layout |
| **L2** LAYOUT SPOTLIGHT | plan dimmed, one zone at full strength in a red box | one room, one point — the study, the bathroom door |
| **L3** LAYOUT SPLIT | plan left with a red box, that zone blown up 2.2× right | when detail matters — a kitchen with no door, a dining that blocks the entry |
| **L4** LAYOUT + AREAS | plan with the developer's numbered pins, room areas listed right, total | the three dimensioned units only: 732, 1,055, 1,367 |
| **C1** COMPARE | two-up: TR left, neighbour right, grid + transaction below | every "against the neighbours" beat — `C1_compare.png` |
| **R1–R3** RECONFIG | one zone of a plan, three frames: as drawn → the moves annotated → the result tinted | any "here's what I'd do to this room" — built for the 1,485 study; reusable on the 1,152 hackable wall |

**Rotation rule:** in any layout segment, never two of the same template
back to back, and never more than 45 s on any single display without a cut
to Edmund full-frame. Edmund full-frame is the ninth display and it is the
default whenever he's giving an opinion.

**Assets:** clean plans `public_thomson_reserve/compare/plans/*_clean.png`
(TR plans have no `_clean` suffix — they were clean from the PDF) · site plan
`compare/site/siteplan_clean_notext.png` with every stack's pixel position in
`stack_coords.json` · drone photos `compare/views/photos/view1..8.png` with
`INDEX.json` naming the direction of each · key maps `keymap_p25..28.png`.
