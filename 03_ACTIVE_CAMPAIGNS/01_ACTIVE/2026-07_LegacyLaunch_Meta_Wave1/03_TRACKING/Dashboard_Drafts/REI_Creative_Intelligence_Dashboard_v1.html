DECISION PROTOCOL — Top Media Buyer Standard

  • Day 1–2 (SGD 0–80): Watch Hook Rate only. Don't kill early based on CPL — not enough data.
  • SGD 80 reached: Apply kill rules. Hook Rate <25% = KILL. CPL >2× account average = KILL.
  • SGD 80–150: WATCH zone. Let borderline ads continue to 150 before deciding.
  • Scale signal: Hook Rate >35% + CPL on target + 3+ bookings → duplicate ad set → increase budget 20% every 48h (not more — let Facebook's algorithm stabilize).
  • When scaling: Do NOT edit the winning ad. Duplicate the entire ad set and increase budget on the duplicate.
  • Creative fatigue: Monitor CTR drop >30% from peak over 7 days = refresh creative. Keep same angle, change visual.

HOW TO CONNECT LIVE DATA

This dashboard runs on local data you enter manually. To pull live data automatically from Meta Ads and GHL, follow the steps below. You'll need a developer (or use Make/Zapier as a no-code bridge).

Option 1 — Meta Marketing API (Direct)

Pull ad performance metrics directly from your Meta Ad Account.

Step 1 — Get your credentials

  • Go to developers.facebook.com → My Apps → Create App
  • Add the Marketing API product to your app
  • Generate a User Access Token with ads_read + ads_management permissions
  • Get your Ad Account ID from Meta Ads Manager → Settings → Account ID

Step 2 — Pull ad insights via API

# Python — pull last 30 days of ad performance import requests, json AD_ACCOUNT_ID = "act_XXXXXXXXXX" # your account ID ACCESS_TOKEN = "YOUR_TOKEN_HERE" BASE_URL = f"https://graph.facebook.com/v19.0/{AD_ACCOUNT_ID}/insights" params = { "fields": "ad_name,spend,impressions,video_thruplay_watched_actions,video_p25_watched_actions,clicks,cpm,actions", "level": "ad", "date_preset": "last_30d", "access_token": ACCESS_TOKEN } r = requests.get(BASE_URL, params=params) data = r.json()["data"] # data = list of dicts, one per ad # Map into dashboard JSON format and paste into window.adData below

Step 3 — Map to this dashboard

Replace the window.adData array in the script section of this HTML file with the output from the API call. The dashboard will auto-render.

Option 2 — Make / Zapier (No-Code)
  • Make.com → Create a Scenario → Meta Ads module → "Get Ad Insights"
  • Schedule it to run daily at 8am Singapore time
  • Output to Google Sheets → share sheet → use Google Sheets API to read into this dashboard
  • Or output directly to a webhook that updates window.adData in this file
Option 3 — GHL Lead Quality Input

GHL doesn't have a public API for ad attribution, but you can:

  • Add a custom field to GHL contacts: "Ad Source" (map to the ad name from Meta)
  • Use UTM parameters on all ad landing pages: utm_content=LL_LGR_MATH_v1
  • GHL reads UTMs → stores in contact record → you can export and count per ad name
  • Enter "Booked Sessions" count weekly in the Tracker tab (col P) by filtering GHL contacts by Ad Source

UTM Template for all landing page URLs:

https://your-lp.com?utm_source=meta&utm_medium=paid_social&utm_campaign=LL_LGR&utm_content=LL_LGR_MATH_MathDoesntLie_v1
