## 1. Purpose of This Engine

The **Legacy Launch Image Prompt Engine v1.0** converts the Legacy Launch campaign strategy into high-quality, repeatable, non-random image ad prompts.

This engine does **not** replace the campaign strategy files. It controls **how the image should look, vary, and be tested**.

### Core principle

> We do not lock the output to one fixed look. We lock the output to one strategic message and allow controlled creative variation.

### What this engine must solve

1. Prevent random image generation.
2. Prevent every image from looking the same.
3. Keep all visuals advisory-led, not project-selling.
4. Create controlled variation across creative format, founder presence, colour mode, typography mode, layout mode, copy density, and experimentation level.
5. Make every image asset testable, trackable, and connected back to the Concept Batch Map.
6. Help the AI act like a **creative director** before it becomes a prompt generator.

## 4. Global Image Output Rules

### Format rules

- Primary format: square **1:1**, **1080 x 1080 px**.
- Suitable for Meta / Instagram feed ads by default.
- Keep important text away from edges.
- Use clear hierarchy and high legibility.
- The image should be understandable in 2 seconds and valuable by 5 seconds.

### Text rules

- Render the exact headline and CTA if provided.
- Do not paraphrase campaign-critical copy without instruction.
- Use short, sharp text wherever possible.
- For image-generation tools, treat embedded text as a draft layer. Always verify text accuracy before publishing.
- If the AI image model cannot render exact text reliably, generate the visual layout first and finalise text in Canva, Figma, Photoshop, or the design tool.

### Compliance rules

Do not use:

- guaranteed-profit language
- guaranteed return claims
- “best return” / “sure-win” positioning
- fear-based countdown language
- fake urgency such as “last chance” unless it is factually true and compliant
- fake government / MAS / URA / HDB endorsement
- real news outlet logos or trade dress
- celebrity or public-figure likeness
- copyrighted meme templates
- unrealistic profit claims
- before/after wealth claims that imply certainty
- named real-person case results unless properly anonymised and compliant
- project-selling tone such as “limited units,” “near MRT,” “don’t miss this launch” as the main hook
- overhyped luxury-brochure styling
- cluttered property flyer design

### Specific visual exclusions already agreed

- Do **not** use staircase, ladder, or rung visuals. These are reserved and should not become public-facing visual shorthand.
- Do **not** use the words **belief** or **mindset** inside the final ad creative text.
- If people are shown, they should read as Singaporean / Singapore-based property owners, not generic Western stock characters.

## 6. AI Intake & Creative Variation Selector

The engine must not generate prompts blindly.

Before producing image prompts, the AI must act as a **creative director** and decide which creative variation is most suitable for the campaign objective, audience temperature, platform, and testing goal.

### 6.1 Intake Check

Before generating image prompts, check whether the following are already provided:

1. Campaign Door
2. Concept Batch ID
3. Audience / Core Buyer Profile
4. Situation Code
5. Awareness Stage
6. Readiness Tier
7. Main Campaign Objective
8. Platform
9. Audience Temperature
10. Desired CTA
11. Preferred Output Count
12. Whether to prioritise safe core formats, authority formats, native formats, experimental formats, or a mix

If enough information is available from the Concept Batch Map, proceed without asking unnecessary questions.

If important context is missing and affects creative quality, ask only the minimum number of questions needed.

### 6.2 Minimum Clarifying Questions

Ask these only when the answer is not already clear:

1. Is this image for cold traffic, warm retargeting, or hot follow-up?
2. What is the main goal: comments, WhatsApp replies, clicks, diagnostic starts, or consult bookings?
3. Should the image feel more premium advisory, raw/native, founder-led, data-driven, emotional, warning/risk-oriented, or experimental?
4. Is this for Meta/Instagram feed, story, carousel cover, LinkedIn, YouTube Community, or another platform?
5. Do you want safer proven formats, aggressive testing formats, or a mix?

Do not ask more than 5 questions unless absolutely necessary.

If the user says **“just decide”**, choose the strongest recommended setup based on the concept batch and campaign objective.

### 6.3 Creative Variation Recommendation Rule

Before creating prompts, recommend the strongest creative variations.

For each concept batch, recommend:

1. Best Core Variation
2. Best Authority Variation
3. Best Native / Social Variation
4. Best Experimental Variation
5. Best CTA Direction

Each recommendation must explain briefly why it is worth testing.

### 6.4 Variation Selection Logic

| Situation | Prioritise These Formats |
|---|---|
| Cold traffic | Scroll-stop, private thought, native formats, simple diagnostic hooks, curiosity, low-friction CTA |
| Warm audience | Advisory trust, founder authority, dashboards, scorecards, case-review style, stronger review CTA |
| Hot audience | Consult readiness, decision clarity, risk map, diagnostic board, case review, direct booking CTA |
| Problem-aware audience | Private thought, gap chart, warning label, myth vs truth, notes app, relatable native formats |
| Solution-aware audience | Advisory dashboard, decision tree, scorecard, founder diagnostic board, comparison matrix, tool screenshot style |
| Product-aware / consult-aware audience | Founder case review, diagnostic report style, consult checklist, before/after strategy map, premium authority report |

### 6.5 Creative Variation Tiers

| Tier | Name | Use Case |
|---|---|---|
| Tier A | Core Proven Format | Stable, clear, advisory-led, lower risk, suitable for first test |
| Tier B | Authority Format | Founder-led, report-style, diagnostic, premium, suitable for trust building and retargeting |
| Tier C | Native Social Format | Less polished, more organic, good for scroll-stop and relatability |
| Tier D | Experimental Format | Trend-led, unusual, platform-native, AI visual, comic, screenshot, meme-adjacent, or new design pattern |

### 6.6 Recommended Output Mix

For a standard 3-image test:

1. **Version 1:** strongest Core Proven Format
2. **Version 2:** strongest Authority or Founder-Led Format
3. **Version 3:** Native Social or Experimental Format

For a 5-image test:

1. **Version 1:** Core Proven Format
2. **Version 2:** Authority / Founder Format
3. **Version 3:** Native Social Format
4. **Version 4:** Data / Dashboard Format
5. **Version 5:** Experimental Open Trend Format

### 6.7 Do Not Randomise the Strategy

Only creative execution can vary.

The following must remain aligned with the Concept Batch Map:

- audience
- private thought
- belief block / hidden assumption
- reframe
- mechanism
- CTA direction
- tracking ID

The following may vary:

- creative format
- founder presence
- colour mode
- typography mode
- layout mode
- text density
- image tone
- experimental style

### 6.8 Creative Director Output Before Prompting

Before generating final prompts, the AI should show:

1. selected campaign objective
2. audience temperature
3. recommended creative variations
4. why each variation is worth testing
5. which variation should be produced first
6. which variation is most experimental
7. which variation is most likely to drive quality consult leads

Only after this should the AI generate the image prompts.

### 6.9 Default Decision Rule

If no extra direction is provided, default to:

- 1 premium advisory / core proven version
- 1 founder authority version

This gives strategic consistency plus creative variety.

## 8. Founder Authority Layer

Founder should be treated as an optional creative layer, not a compulsory design element.

Founder presence can increase trust, familiarity, and advisory authority, but it should not appear in every image. It should be used when it improves credibility, human connection, or consult readiness.

### When to use founder layer

Use founder layer when the creative needs:

- authority
- trust
- founder POV
- advisor diagnosis
- warm audience retargeting
- consult positioning
- objection handling
- case review feel
- a human bridge from content to consultation

Avoid founder layer when:

- the image needs to feel very native / screenshot-like
- the concept is better expressed as a private thought
- the ad needs to look less branded and more organic
- the visual metaphor is stronger without a person

### Founder Authority Formats

| Founder Format | Best For | Visual Direction |
|---|---|---|
| Founder Quote Card | Thought leadership, authority, sharp reframe | Edmund or Edmund & Cindior photo/silhouette with one strong quote |
| Founder POV Desk Note | Advisory intimacy, “reviewing your case” feel | Laptop/tablet/property notes/calculator/handwritten annotations |
| Founder Diagnostic Board | Strategy frameworks and consult-preview | Founder beside whiteboard/digital board with 3 questions or map |
| Founder Reaction / Native Creator | Cold/social-native scroll stop | Founder cutout/reaction with bold spoken headline |
| Founder Case Review | Warm audience, serious consideration | Anonymised owner case snapshot with advisory notes |
| Founder Whiteboard Breakdown | Education, reels cover, simple framework | Founder + board + arrows + short diagnostic point |
| Founder Advisory Screenshot | Consult preview and tool positioning | Mock report/diagnostic screenshot with founder note overlay |
| Founder vs Agent Contrast | Positioning against project-selling | Side-by-side: project seller vs property strategist |

### Founder layer rule

Founder should make the image feel more trustworthy, not more ego-driven. The point is not “look at Edmund.” The point is “this is an advisor-led review, not a random property ad.”

### 5 filters for any new experimental format

A new experimental format is allowed if it passes all 5 filters:

1. **Concept Fit:** It still carries the correct concept batch message.
2. **Audience Fit:** It still feels suitable for Singapore property owners.
3. **Trust Fit:** It preserves advisory trust and does not damage credibility.
4. **Tracking Fit:** It can be given a clear creative code and tracking ID.

> Any new creative format is allowed if it protects strategy, trust, compliance, and tracking.

Do not lock every image into one font family.

> Use typography that matches the selected visual mode. Prioritise legibility, hierarchy, and fast comprehension over decorative styling.

| Typography Mode | Best For | Font Feel |
|---|---|---|
| Premium Advisory Typography | Dashboards, consult positioning, founder quote | Modern sans-serif, strong headline, clean subtext, small uppercase labels |

## 18. Anti-Repetition Rules

To avoid creative fatigue, follow these rules:

1. Do not use the same creative format more than twice in one 5-image batch.
2. Do not use the same colour mode for every version.
3. Do not use founder presence in every asset.
4. Do not use only polished premium designs; include at least one native/social variation in major batches.
5. Do not use only native/UGC designs; preserve advisory trust with at least one premium or authority format.
6. Rotate text density: at least one low-text asset and one medium/high-insight asset in larger batches.
7. Rotate CTA intensity: cold assets should use low-friction CTAs; warm/hot assets can use review or consult CTAs.
8. If two assets share the same concept batch and format, they must differ by mode, layout, headline structure, or CTA.
9. Use Open Trend Slot only when it still passes concept, audience, trust, tracking, and testing filters.
10. Do not change the strategic reframe just to create visual variety.

## 19. Platform Adaptation Rules

### Meta / Instagram Feed

- Default 1:1 square.
- Strong headline hierarchy.
- Works well for image ads, organic posts, retargeting, and carousel covers.

### Instagram / Facebook Stories

- Adapt to 9:16.
- Reduce text density.
- Use larger headline and simple visual focal point.
- CTA should be lower-third or sticker-friendly.

### Carousel Cover

- Use strongest headline and simplest visual metaphor.
- The cover should create curiosity to swipe.
- Do not overload the cover with explanation.

### LinkedIn

- Slightly more editorial/report-like.
- Authority and insight should be stronger than meme/native treatments.
- Founder layer and case-review style can work well.

### YouTube Community / Thumbnail Support

- Use bigger headline and higher contrast.
- The image must read clearly at small size.
- Founder reaction and warning labels can work well.
