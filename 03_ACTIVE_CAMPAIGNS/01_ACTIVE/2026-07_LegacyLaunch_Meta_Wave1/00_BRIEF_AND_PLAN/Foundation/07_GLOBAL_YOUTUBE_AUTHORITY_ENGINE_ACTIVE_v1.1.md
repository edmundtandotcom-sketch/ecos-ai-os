## 1. Purpose of This Engine

The Client Edition YouTube Authority Engine v1.1 is the master system for creating long-form YouTube videos that build authority, educate the market, pre-sell the viewer, support consult conversion, and generate reusable short-form content across other channels.

This is not a generic YouTube script template. It is a production control system for authority-led businesses where one long-form episode should become a mother asset for multiple downstream assets.

Core operating idea:
AUTHORITY-FIRST + REPURPOSE-READY + CONVERSION-AWARE

This means every episode must work in three ways:
- as a standalone YouTube video that viewers can watch and trust;
- as a source asset that produces reels, shorts, images, carousels, captions, email, and WhatsApp content;
- as a soft conversion asset that moves the right viewer toward a review, consultation, diagnostic, application, or next-step conversation.

This engine can be used for property campaigns and non-property topics. Legacy Launch is one application, not the only use case.

## 3. Guided Direction Intake Protocol

Every YouTube episode must start with a guided direction intake before the full script is written.

The user should not need to start from zero. The AI must help define the direction, flow, angle, structure, and output plan before writing the episode.

Core rule:
DO NOT write the full YouTube script immediately unless the episode direction is already clear.

First, the AI should either:
- ask focused direction questions;
- infer a recommended direction from existing campaign context;
- or produce a proposed Episode Direction Board for user approval.

This applies to property and non-property topics.

### 3.1 Why This Intake Exists

Long-form YouTube has too many moving parts to start with a blank script.

Before scripting, the AI must clarify:
- who the episode is for;
- what belief, problem, or question the episode must resolve;
- what format the episode should use;
- what title and thumbnail promise should lead the episode;
- what proof, examples, or frameworks should be used;
- what CTA path should be used;
- what playlist and next-video path the episode belongs to;
- what reel clips should be intentionally created from the episode.

The purpose is to make the AI act like a YouTube strategist and episode producer first, not just a scriptwriter.

### 3.2 Intake Modes

Use three intake modes depending on how much direction already exists.

Mode A - Quick Direction Intake
Use when the user already has a clear topic.
Ask 5 key questions:
1. Who is this video mainly for?
2. What is the main problem or private thought we want to address?
3. What should the viewer understand differently after watching?
4. What action should they take after the video?
5. Should this be 8-12 min, 20-30 min, or 45-60 min?

Mode B - Full Episode Blueprint Intake
Use when the topic is broad, strategic, or high-value.
Ask up to 12 questions:
1. What is the topic or working idea?
2. Who is the target viewer?
3. What is the viewer's current belief or wrong question?
4. What is the hard truth or reframe?
5. What outcome should the episode create?
6. What proof, examples, stories, or case patterns can be used?
7. What should not be said because of compliance, privacy, or positioning?
8. Which episode type fits best?
9. What CTA should be used?
10. Which playlist should this belong to?
11. What reels or shorts should we intentionally extract from this episode?
12. Are there any visuals, charts, tools, screenshots, or whiteboard sections needed?

Mode C - AI Recommended Direction
Use when the user says "just decide", "you already know", or gives a rough topic only.
The AI should not get stuck waiting for perfect input.
Instead, it should produce a recommended direction and clearly state assumptions.

### 3.3 Episode Direction Board

Before writing the script, the AI should produce an Episode Direction Board.

The board should include:
- Working Topic
- Target Viewer
- Viewer Stage
- Core Private Thought
- Wrong Question / Hidden Assumption
- Hard Truth
- Strategic Reframe
- Episode Type
- Recommended Duration
- Core Framework / Teaching Flow
- Proof / Example Needed
- Title Angle
- Thumbnail Promise
- Description Angle
- Primary Playlist
- Secondary Playlist if useful
- CTA Path
- Retention Loops
- Clip Extraction Plan
- Visual Production Notes
- Compliance / Positioning Guardrails

Only after this board is approved, or after the AI has stated its assumptions, should the full script be written.

### 3.4 Question Asking Rules

The AI should be helpful, not annoying.

Rules:
- Do not ask 20 questions when 5 will do.
- If the user gives enough context, ask only the missing questions.
- If the user wants speed, recommend a direction instead of forcing a long intake.
- If the topic is high-stakes, proof-heavy, or compliance-sensitive, ask more questions before writing.
- If the user is creating many episodes, reuse prior campaign context and only ask what is new.
- Always turn answers into a structured Episode Direction Board before scripting.

### 3.5 Script Start Rule

The script should begin only after one of these conditions is met:
- the user answers the intake questions;
- the user approves the Episode Direction Board;
- or the AI states the assumptions it will use and proceeds with a recommended direction.

This keeps every YouTube episode strategic and prevents blank-page scripting.

## 4. What YouTube Does for Client Edition

YouTube is not only for views. In this system, YouTube has seven business roles:

1. Authority Positioning
Make viewers feel: this person thinks deeper than the usual market.

2. Pre-Consult Education
Warm viewers before they WhatsApp, book, apply, or speak to the team.

3. Objection Removal
Answer doubts before they become sales-call resistance.

4. Evergreen Search Asset
Keep working after the original posting date.

5. Trust Transfer
Let a cold viewer spend 20-60 minutes with the advisor before taking the next step.

6. Content Mother Asset
One episode becomes reels, shorts, image posts, carousels, captions, WhatsApp messages, email angles, and retargeting clips.

7. Demand Qualification
Attract viewers who value depth, structure, and advisory thinking, not just quick tips.

Wrong use of YouTube:
- turning every long video into a sales pitch;
- stretching a shallow idea into 60 minutes;
- posting long videos with no title/thumbnail strategy;
- filming first and only later asking what clips to cut;
- ending with a strong CTA but no trust journey before it.

## 5. When a Topic Deserves Long-Form YouTube

Not every topic deserves 45-60 minutes.

A topic deserves long-form treatment when it has at least four of these qualities:
- high audience anxiety;
- high decision value;
- high misunderstanding in the market;
- multiple wrong beliefs to correct;
- multiple objections to handle;
- strong search or evergreen potential;
- strong authority payoff;
- real examples, case patterns, or frameworks to explain;
- enough clip-worthy moments to repurpose;
- direct relevance to a paid consult, review, application, sale, or strategic next step.

Do not make a 45-60 minute video if the topic can be fully explained in 8-12 minutes. Long-form should feel earned, not padded.

Topic qualification rule:
If the topic has one simple answer, make a short video.
If the topic has several wrong assumptions, decisions, traps, examples, objections, and next-step implications, make a long-form authority episode.

## 6. Episode Type Library

Choose the episode type before writing the script. Different episode types require different flow.

1. Strategic Explainer
Best for: a major misconception or framework that needs 20-30 minutes.
Structure: problem -> wrong thinking -> framework -> examples -> CTA.

2. Deep-Dive Advisory Episode
Best for: complex decisions with many factors.
Structure: viewer reality -> traps -> framework -> cases -> objections -> action plan.

3. Authority Masterclass
Best for: 45-60 minute flagship content.
Structure: promise -> deep mirror -> wrong question -> framework -> scenarios -> objections -> decision checklist -> CTA.

4. Case Review / Scenario Breakdown
Best for: anonymised examples and practical decision logic.
Structure: situation -> options -> hidden risk -> advisory lens -> what to review.

5. Market Misread Breakdown
Best for: correcting popular but incomplete views.
Structure: common market belief -> what is missing -> better interpretation -> action implications.

6. Framework Teaching Episode
Best for: method-led authority.
Structure: named framework -> each part explained -> example -> mistakes -> application.

7. Owner / Client / Audience Decision Map
Best for: showing paths and consequences.
Structure: decision branches -> trade-offs -> safety checks -> next move.

8. Tool Walkthrough Episode
Best for: diagnostic tools, calculators, scorecards, dashboards, or HTML outputs.
Structure: tool result -> what it means -> mistakes -> how to act.

9. Objection Handling Episode
Best for: hot or hesitant audiences.
Structure: top objections -> why valid -> what to check -> better next step.

10. Live Advisory / Q&A Episode
Best for: building trust and showing thinking in real time.
Structure: question clusters -> live answers -> recurring patterns -> summary.

11. VSL-Style Authority Episode
Best for: warm audience and consult conversion.
Structure: hook -> mirror -> belief shift -> method -> proof -> CTA.

12. Repurposing-First Roundtable / Interview
Best for: conversations that can produce many short clips.
Structure: themed questions -> sharp answers -> clip markers -> summary.

## 7. Topic-to-Format Decision Rules

8-12 minute authority video:
Use when the topic is specific, narrow, and can be explained with one framework or one reframe.

20-30 minute strategic explainer:
Use when the topic has several traps, examples, and a clear method, but does not need full masterclass depth.

45-60 minute authority masterclass:
Use when the topic is a major campaign pillar or evergreen conversion asset.

Live / Q&A:
Use when you want to capture real objections, real audience language, or create fast clips from repeated questions.

Tool walkthrough:
Use when the audience needs to see a diagnostic, calculator, map, or report output to understand the issue.

Decision rule:
If the video is likely to become a campaign pillar, give it the full packaging, description, chapter, CTA, and repurposing treatment.

## 8. Title and Thumbnail Packaging System

For YouTube, title and thumbnail are not decoration. They are part of the hook.

Before scripting, create at least three title angles and three thumbnail angles.

Title angle types:
- Problem title: names the pain directly.
- Curiosity title: creates a knowledge gap.
- Contrarian title: challenges common belief.
- Decision title: helps viewer choose between options.
- Mistake title: names what people get wrong.
- Framework title: promises a method.
- Case title: uses a scenario or pattern.
- Search title: includes exact search phrase the audience would type.
- Outcome title: points to desired clarity or transformation.
- Warning title: names risk without fearmongering.

Thumbnail rules:
- one visual idea only;
- 2-5 words where possible;
- strong contrast between current state and better state;
- founder face only if it increases trust or curiosity;
- avoid tiny charts and crowded text;
- use emotional clarity, not random design decoration;
- thumbnail should create the question the title answers.

Packaging formula:
Viewer identity + uncomfortable gap + promise of clarity.

Examples for property:
- Title: Your Condo Made Money. Why Are You Still Stuck?
- Thumbnail: PAPER GAIN. NO PLAN?

Example for non-property business topic:
- Title: Your Leads Are Coming In. Why Are Sales Still Slow?
- Thumbnail: LEADS. NO SALES?

## 9. YouTube Description System

Every long-form YouTube video needs a planned description. Do not write descriptions as an afterthought.

Description structure:

1. Search-Friendly Opening
2-3 sentences summarising who the video is for, the problem, and what the viewer will learn.

2. Learning Bullets
3-7 bullets on the key ideas in the video.

3. Main CTA Block
One primary next step. For example: book a review, complete a diagnostic, WhatsApp a keyword, download a checklist, or watch the next video.

4. Chapter Timestamps
Long-form videos should include timestamps. These help retention, search clarity, and viewer navigation.

5. Related Videos / Playlist Links
Link viewers into the next relevant video or playlist.

6. Resource Links
Diagnostics, tools, lead magnets, newsletters, WhatsApp, application pages, or consultation links.

7. Compliance / Disclaimer
Use when discussing finance, property, health, business outcomes, or regulated topics.

Description rule:
The description should support search, trust, conversion, and session depth. It should not be a generic paragraph with a random link.

## 11. 45-60 Minute Master Episode Structure

Use this for flagship authority episodes and masterclass-style videos.

0:00-2:00 Hook + Promise + Who This Is For
- Start with the central tension.
- Name who should watch.
- Promise the clarity they will receive.
- Open 1-2 strategic loops.

2:00-8:00 Deep Mirror / Viewer Reality
- Describe the viewer’s current situation.
- Use real scenes, not vague feelings.
- Name the private thought or unspoken tension.

8:00-15:00 Wrong Question / Lie / Hard Truth
- Explain the question most people are asking.
- Name why it is incomplete.
- Drop the hard truth.
- Prepare the reframe.

15:00-25:00 Reframe + Core Framework
- Introduce the better way to think.
- Name the framework.
- Explain the 3-5 parts.
- Show how the framework changes the decision.

25:00-38:00 Scenario / Case Pattern / Worked Examples
- Use examples, anonymised patterns, or practical scenarios.
- Show how the framework applies differently across situations.
- Mark 2-4 clip-worthy moments.

38:00-48:00 Objections / Edge Cases / What-Ifs
- Address likely viewer doubts.
- Validate the concern.
- Reframe with the method.
- Show what needs to be checked.

48:00-55:00 What To Do Next / Decision Checklist
- Summarise what the viewer should do next.
- Give a checklist, diagnostic, or decision map.
- Prepare for final CTA.

55:00-60:00 Final CTA + Next Video Open Loop
- Invite the primary next step.
- Point to the next video or playlist.
- Close with calm authority.

60-minute rule:
Every 5-8 minutes, the episode should shift visual mode, introduce a new loop, answer a loop, or move to a new chapter. No long flat monologue blocks.

## 13. 8-12 Minute Authority Video Structure

Use this for narrower YouTube topics and high-speed authority content.

0:00-0:45 Hook + Stakes
0:45-2:00 Who this is for + viewer reality
2:00-4:00 Wrong belief / hard truth
4:00-7:00 Framework or explanation
7:00-9:00 Example or application
9:00-11:00 What to do next
11:00-12:00 CTA + next video

Best for:
- one key reframe;
- one decision factor;

- one major objection;
- one short educational topic.

This format should still be clip-aware, but it will usually produce 2-4 clips, not 10.

## 14. Opening 2-Minute Hook System

The first 2 minutes determine whether viewers trust the video enough to stay.

Opening must include:
- a clear problem or tension;
- who the video is for;
- what they will understand by the end;
- why the usual way of thinking is incomplete;
- one strategic open loop;
- no long greeting before the hook.

Opening formats:

Direct Diagnosis:
“If you are in this situation, the real issue is not X. It is Y.”

Private Thought:
“You may not say this out loud, but you might be wondering...”

Contrarian:
“Most people think this is about X. I think that is too early.”

Story Open:
“A client / owner / founder came in thinking X. By the end, the real issue was Y.”

Checklist Promise:
“By the end, you will have the 5 checks to know whether...”

Avoid:
- “Hi everyone, welcome back...” before the hook;
- long background story before stakes;
- generic market commentary with no clear problem;
- opening with a logo animation instead of a reason to watch.

## 15. Deep Mirror System

Long-form YouTube needs a deeper mirror than a reel.

Mirror should make the viewer feel understood before you teach.

Use three levels:

Surface Reality
What they are doing or seeing.
Example: They are comparing options, reading news, watching videos, asking friends.

Private Thought
What they think but may not say.
Example: “I know I should do something, but I am not sure if moving is actually safer.”

Decision Pressure
What happens if they delay or choose wrongly.
Example: The decision becomes more expensive, the options narrow, or the family alignment gets harder.

Mirror rule:
Do not describe vague emotions like “you feel confused” too often. Show real scenes, real decisions, and real contradictions.

## 16. Wrong Question, Hard Truth, and Reframe System

A strong authority episode should not only answer the viewer’s question. It should improve the question.

Wrong Question:
The question the viewer is currently asking too early.
Example: “Which project should I buy?”

Hidden Assumption:
The belief underneath the question.
Example: “A good project will automatically make the move safe.”

Hard Truth:
The blunt statement they cannot easily argue with.
Example: “A good project cannot fix a wrong sequence.”

Reframe:
The better way to think.
Example: “Before asking what to buy, review what your current position should unlock next.”

YouTube authority comes from helping the viewer ask a better question than the market is asking.

## 17. Framework Teaching Layer

Long-form YouTube should usually teach a named framework, decision map, checklist, or diagnostic lens.

A framework makes your advice memorable and repurposable.

Framework rules:
- 3-5 parts is ideal;
- each part must have a clear job;
- avoid clever names that confuse laypeople;
- explain the framework before showing examples;
- repeat the framework at the end;
- turn each framework part into possible clips.

Framework examples:
Property: Life, Money, Exit, Safety, Sequence.
Business: Lead Flow, Sales Process, Offer Fit, Follow-Up, Fulfilment.
Personal finance: Income, Cash Flow, Protection, Growth, Retirement.
AI productivity: Capture, Sort, Prompt, Produce, Review.

The framework is the hero. The founder is the guide.

## 18. Scenario, Case Pattern, and Proof Layer

Long-form needs practical application. Use scenarios, case patterns, or proof to make the framework real.

Allowed proof formats:
- anonymised case pattern;
- composite scenario clearly labelled as composite;
- founder’s own story;
- diagnostic walkthrough;
- framework application;
- market observation;
- approved numbers only;
- before/after clarity, not guaranteed outcome.

Do not invent results.
Do not use private client details without approval.
Do not turn the case into a guarantee.
Do not over-focus on profit when the strategic goal is clarity, safety, sequence, or decision quality.

Scenario structure:
1. Current situation.
2. What they thought the question was.
3. What the real issue was.
4. Which part of the framework revealed the gap.
5. What should be reviewed next.

## 19. Objection and Edge Case Layer

Long-form should handle objections before the viewer leaves or brings resistance into a consult.

Objection categories:
- I am not ready.
- What if the market changes?
- What if I make the wrong move?
- What if my spouse disagrees?
- What if the numbers do not work?
- What if waiting is safer?
- What if I already have something that is “good enough”?
- What if I do not want to be sold anything?

Objection handling structure:
1. Validate the concern.
2. Explain why the concern is reasonable.
3. Show what question is still missing.
4. Apply the framework.
5. Give a non-pushy next step.

This layer is where long-form YouTube becomes pre-consult education.

## 20. Retention Loop System

Retention loops should be strategic, not clickbait.

Types of loops:

Opening Loop
Placed in the first 2 minutes.
Example: “Later, I will show you the 3 checks that decide whether this is still serving you.”

Chapter Loop
Placed before a new chapter.
Example: “The next part is where most people get the wrong conclusion.”

Proof Loop
Placed before examples.
Example: “I will show you how the same issue appears in three very different situations.”

Objection Loop
Placed before objections.
Example: “If you are thinking, ‘But what if I am not ready?’ this next section is important.”

CTA Loop
Placed before a practical action section.
Example: “Before you decide anything, use this checklist first.”

Next-Video Loop
Placed near the end.
Example: “In the next video, I will break down the specific decision between holding and exiting.”

Retention rule:
Every 5-8 minutes, either open a loop, close a loop, shift visual mode, summarise a milestone, or move to a new question.

## 21. Strategic CTA Placement System

Micro CTAs are not outdated. Random interruption CTAs are outdated.

Replace constant “like, subscribe, click below” interruptions with Strategic CTA Layering.

CTA Layer 1 - Engagement CTA
Timing: 5-10 minutes.
Purpose: make the viewer participate mentally.
Examples:
- “As you watch, identify which of these situations sounds most like you.”
- “Comment which stage you think you are in.”

CTA Layer 2 - Trust Bridge CTA
Timing: 18-30 minutes.
Purpose: connect education to application.
Examples:
- “This is why we review the position before discussing options.”
- “If this is making you rethink your situation, do not rush into a decision. Review the position first.”

CTA Layer 3 - Low-Friction Action CTA
Timing: 35-50 minutes.
Purpose: give the viewer an easy action before the final ask.
Examples:
- “Write down your current position, goal, time frame, and main concern.”
- “Start with the diagnostic or checklist linked below.”

CTA Layer 4 - Primary Conversion CTA
Timing: final 5-8 minutes.
Purpose: invite the main next step.
Examples:
- “Book a review.”
- “WhatsApp us with the keyword.”
- “Complete the diagnostic.”
- “Apply for the session.”

CTA Layer 5 - Next-Video CTA
Timing: final 1-2 minutes.
Purpose: increase session depth.
Example:
- “Watch this next if you are deciding between X and Y.”

CTA rule:
Use micro CTAs as bridges, not interruptions. The final CTA should be clear, but the earlier CTAs should feel like part of the learning journey.

## 22. Clip-Aware Scripting Architecture

Every long-form episode should be scripted so clips can be extracted naturally.

Do not film first and then hope clips appear later. Build clip-worthy blocks into the script.

Clip-worthy block types:
- Big premise clip;
- Private thought clip;
- Hard truth clip;
- Wrong question clip;
- Reframe clip;
- 3-question diagnostic clip;
- Framework step clip;
- Case pattern clip;
- Objection answer clip;
- Checklist clip;
- Founder POV clip;
- Tool walkthrough clip;
- Next-step clip.

When writing the script, tag moments as:
[CLIP CANDIDATE]
[REEL HOOK]
[SHORT-READY ANSWER]
[CAROUSEL IDEA]
[IMAGE POST ANGLE]
[WHATSAPP BROADCAST ANGLE]

Clip rule:
A clip should be understandable without the full episode, but still make the full episode feel valuable.

## 23. Repurposing Map System

Every episode should produce a repurposing map before filming.

Minimum output from a 45-60 min episode:
- 5-10 reels or shorts;
- 3-5 image post angles;
- 1 carousel angle;
- 1 WhatsApp or email broadcast;
- 1 retargeting clip;
- 1 pinned comment angle;
- 1 related next-video angle.

Repurposing map fields:
- clip number;
- source chapter;
- timestamp target;
- short-form hook;
- clip purpose;
- platform fit;
- CTA;
- caption angle;
- visual notes;
- whether it supports cold, warm, or hot audience.

Example:
Clip 03: Hard Truth section.
Short hook: “Appreciation is not progression.”
Purpose: belief shift.
Platform: Reel / YouTube Short / LinkedIn clip.
CTA: Watch full breakdown or take diagnostic.

## 24. Visual Production Layer

A 45-60 minute episode should not be one flat talking-head recording.

Visual modes:
- founder direct-to-camera;
- whiteboard or marker board;
- screen share;
- diagnostic tool walkthrough;
- charts or decision maps;
- case table;
- on-screen chapter cards;
- property or topic-specific B-roll;
- document/page walkthrough;
- checklist screen;
- recap cards;
- split-screen comparison.

Recommended visual rhythm for 45-60 min:
0-2 min: face-led hook.
2-8 min: talking head + supporting B-roll.
8-15 min: whiteboard / statement cards.
15-25 min: framework diagram.
25-38 min: scenario table / case pattern / screen share.
38-48 min: objection cards / what-if sections.
48-55 min: checklist / action map.
55-60 min: CTA card + next video.

Visual rule:
Every 5-8 minutes, change the viewer’s visual experience. The change should support the teaching, not decorate it.

## 25. Chapter and Timestamp System

Long-form videos should be structured into chapters before recording.

Chapter rules:
- chapter titles should be useful and clear;
- avoid vague titles like “Part 1” or “More tips”;
- each chapter should answer a specific viewer question;
- chapter timestamps should match the description;
- chapter titles can become clip titles or carousel sections.

Recommended chapter pattern:
00:00 The Problem / Big Promise
02:00 Who This Is For
08:00 The Wrong Question
15:00 The Framework
25:00 Scenario Examples
38:00 Objections and What-Ifs
48:00 What To Do Next
55:00 Review / CTA / Next Video

Chapter rule:
Chapters should improve retention, not just navigation.

## 26. Pinned Comment, Cards, and End Screen Rules

Pinned comment:
Use the pinned comment to guide the next action. It should not just repeat the title.

Pinned comment structure:
- one-line summary;
- main CTA or diagnostic link;
- next related video;
- optional question to drive comments.

Cards:
Use cards when referencing a related topic, diagnostic, or previous video. Do not overuse cards.

End screen:
Use one primary next video and one playlist or subscribe option.

End screen rule:
The next video should continue the viewer’s decision journey. Do not send everyone to the newest upload by default.
