# PART 1 — THE WHOLE BUSINESS, ONE FLYWHEEL

Eight stages. Each one names the exact Taki mechanism it's built from and the Agent Edition asset that already exists (or is proposed) to run it.

```
0. AUTHORITY CONTENT  (ongoing, always running)
        ↓
1. ATTRACT             — cold/warm traffic → free diagnostic
        ↓
2. THE INTENSIVE FUNNEL — Four Campaigns, S$197 event
        ↓
3. THE FIT CALL         — qualify, book the Install
        ↓
4. THE ON-RAMP          — pre-event, same floor for everyone
        ↓
5. THE MULTIPLIER INSTALL — 3-day event (Part 2 of this doc)
        ↓
6. INSTALLATION LABS     — weekly, post-event, the 30/90-day cycle
        ↓
7. THE YEAR + ASCENSION  — Foundation → Acceleration → Multiplication
        ↓
   (results feed back into Stage 0 as content — the loop closes)
```

## Stage 0 — Authority Content (ongoing)

**Taki mechanism:** the Weekly Seven content mine (C2) → Dangerous+Prolific selection (C3) → Brandwidth (C1) → the nine-beat video template (`03_TEACHING_AND_EXPLAINING.md` §4).

**What runs:** Edmund scans seven categories weekly (calendar, clients, DMs, community, creations, consumption, circumstances), picks the ones with real energy, and publishes framework-first content — one Nine-Multiplier concept per piece, drawn live, one strong opinion, one proof point. This is not the S$197 funnel's job; it's what makes the funnel convert once someone reaches it. Real Agent Edition member results (Stage 6/7) are the highest-value input to this category once they exist.

**Existing asset:** none dedicated yet — this is currently Edmund's general content practice, not Agent-Edition-specific. **Open item, not addressed further in this doc** (belongs to Content Studio, not Program Architecture).

## Stage 1 — Attract

**Taki mechanism:** the free-tool principle (give the real thing, not a teaser) + Brandwidth-aware bridges (cold/warm/hot self-selection, per the Design Bible's "Three Conversion Bridges" section).

**What runs:** **The Agent Business Multiplier Score™** — free diagnostic, the front door. Cold traffic gets a simple tool; warm traffic (existing content viewers) gets a case-study/authority-video bridge; hot traffic goes straight to the Fit Call.

**Existing asset:** locked in the offer ladder (`02_PROGRAM_GOVERNANCE_AND_OFFER_LADDER_v2.0.md`). Not yet built as a live tool.

## Stage 2 — The Intensive Funnel

**Taki mechanism:** D5, The Four Campaigns, applied wholesale — this is a webinar-shaped funnel and Taki's webinar system is the closest direct match in his whole library.

| Campaign | What it does | For Agent Edition |
|---|---|---|
| **Sign Up** | 4 emails — Problem, Promise, Proof, Reminder — over 4–10 days | Registration sequence for the S$197 Agent Income Multiplier Live Intensive |
| **Show Up** | Countdown, curiosity handout with open loops, teaser video, SMS (~+10% show rate) | Pre-event sequence; the 30-Day Workbook itself can be the "curiosity handout" — a partially-filled preview |
| **Pay Up** | Teach and sell simultaneously; every element proves capability | The 2.5hr Intensive itself, run on the VSL rule already locked (`02_AGENT_EDITION_BIG_IDEA_POSITIONING_v2.0.md`: painful situation → outcome → why → name → proof → open loop) |
| **Follow Up** | Four segments, four sequences | **Buyers** → Fit Call booking sequence. **No-shows** → replay-equivalent (workbook + summary, since there's no replay). **Early bailouts** → re-engagement. **Watched-but-didn't-enrol** → objection-away content on the top 3 concerns |

**This is the single largest currently-missing piece of the funnel.** The Intensive's *content* (what gets taught) is locked. Its *campaign machinery* (Sign Up/Show Up/Follow Up) does not yet exist as built sequences. Recommend this is the next build after this run sheet is confirmed.

## Stage 3 — The Fit Call

**Taki mechanism:** the Triage Call's structure (D1), deliberately not its name or its full 9-step script — already named in the source material as the **Agent Multiplier Fit Call™**, ~10–15 min.

**What runs:** production → biggest source → least predictable part → desired state → why now → what's been tried → willingness to implement → fit / no-fit. Ends by inviting into Year 1 Foundation (preferred) or The Multiplier Install standalone, or referring out if genuinely not a fit. Never sells on this call — sells the next step, exactly as D1 teaches.

**Existing asset:** the 8-question skeleton exists in the Design Bible (Part XXVIII). Not yet scripted to our voice.

## Stage 4 — The On-Ramp

**Taki mechanism:** B4, The On-Ramp — four short gates before the room, each a 10-min video + worksheet, ending in a 1:1-style prep, so nobody arrives cold.

**What runs, adapted:** Business Numbers (last 12 months: transactions, GCI, sources, conversion) → Best Clients (upload ~20 deals) → Opportunity Map (where business currently comes from) → Time Map (what eats the week). Then an AI pre-diagnosis produces an initial Nine-Multiplier score *before* Day 1 — so Day 1 morning is confirming and deepening a draft score, not building one from zero. This is the single highest-leverage compression available: it turns roughly 90 minutes of Day 1 diagnostic teaching into closer to 45–60, because the room isn't starting blank.

**Existing asset:** described in the Design Bible (Parts XIX–XX) as a 14-day pre-event schedule. Not yet built.

## Stage 6 — Installation Labs (the 30/90-day cycle)

**Taki mechanism:** blends E8 (Monthly Rhythm: Learn/Do/Meet/Mastermind) with the already-locked four-Lab structure (Business Lab / Command Lab / Authority Lab / Conversion Lab) and Taki's shift from 90-day sprints to six-week cycles (E10) — 90 days is kept as the outer measurement window (matches the offer's own "next S$200K" framing) but the *work* inside it runs in a tighter rhythm to avoid sprint fatigue.

**What runs:**
- **Week 1 — Install.** Specialist Lab turns the member's Installation Brief (from The Multiplier Install) into a working system.
- **Week 2 — Activate.** First real conversations/leads/appointments run through it.
- **Week 3 — Review.** Numbers checked, hot seats, bottleneck named.
- **Week 4 — Improve.** Fix the bottleneck, 30-Day Review, choose Priority #2's install date.
- Repeat the cycle for Priority #2.
- **Weekly cadence:** members attend only the Lab relevant to their current Priority Multiplier — no forced attendance across all four, matching E9's modular principle (nobody has to be "caught up" to benefit).

**Existing asset:** named, not scheduled. Cadence/calendar not yet built.

## Stage 7 — The Year + Ascension

**Taki mechanism:** E9, Modular design (every month stands alone, enrolment is continuous) applied to Year 1 Foundation; the identity ladder (Producer→Advisor→Business Owner→Multiplier) as the public-facing version of Taki's plateau ladder (A3, Three Plateaus).

**What runs:** Year 1 Foundation (includes The Multiplier Install + the Lab cycle) → Year 2 Acceleration (additional lead source, paid acquisition, content engine, signature method) → Year 3 Multiplication (associates, technique transfer, leadership). Optional side-ladder: Advisory Conversation Lab / Build Your Method (Year 2) → REI Practitioner (PropNex-practice-only). Quarterly implementation events keep the room's energy alive between Multiplier Installs, mirroring Taki's monthly-workshop-as-profit-centre logic without the monthly cadence being right for this smaller SG market (a call already made in the Taki adoption work).

**The loop closes here:** real Year 1 results become Stage 0's content. This is the mechanism, not a hope — it's why Stage 6's Review weeks matter beyond the member's own business.

# PART 2 — THE MULTIPLIER INSTALL, TIMED RUN SHEET

Governing constraints, all already locked and carried through below without re-litigating:
- 3-2-1 mechanism (diagnose 3, choose 2, install 1 live)
- PLAN → EXPERIENCE → PERSONALISE → QUEUE inside every build block
- 40% teach/context · 40% application · 20% review+brief, target ratio
- One live result per person, non-negotiable
- Recognition not competency for all nine; full build depth only for the member's chosen Top 2
- No consultation/presentation methodology taught (Convert is Lead-to-Appointment, Pre-Sell, Follow Through only)

**Two calls I made below that are genuinely open — flagged inline, not decided for you:** (1) whether the On-Ramp pre-score actually lands before Day 1 in your first cohort, which changes Day 1's morning length; (2) whether Day 3's close is a plain commitment-to-camera or something closer to the old Market Maker "Re-Date" moment (a re-run of a personal number, publicly, for impact) — that mechanic was good and nothing in the source material replaces it.
