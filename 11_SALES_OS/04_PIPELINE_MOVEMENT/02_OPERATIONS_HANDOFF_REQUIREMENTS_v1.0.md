# Operations Handoff Requirements
Version: v1.0
Status: APPROVED
Date: 2026-07-20

A Sales-to-Operations implementation request must include:
- governing stage/outcome and business purpose;
- precise entry/exit criteria;
- actor and event that trigger movement;
- required fields and controlled values;
- messages/tasks/notifications;
- stop, exception and manual-override rules;
- reporting requirement;
- test cases and acceptance owner;
- release timing and rollback.

Operations must return:
- mapped live GHL objects;
- implementation plan;
- privacy/access review;
- test results;
- deployment record;
- live verification evidence.

No dated document may substitute for inspecting current GHL configuration.
